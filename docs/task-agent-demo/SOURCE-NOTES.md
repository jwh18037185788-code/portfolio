# 源码复用与演示适配说明

## 来源与保留

基于当前任务管理 Agent 分支的工作区快照，包含原分支已完成的 UI 调整及三处尚未提交的「重点关注」mock 改动。原项目文件、Git 状态、业务接口、环境与部署配置均保持不变。本次没有提交、推送或发布。

## 直接复用的界面

- `Layout.tsx`：侧栏品牌、导航、主题、展开/折叠、原有布局。
- `TaskWorkbenchPage.tsx` / `FocusTab.tsx` / `AnalysisPage.tsx`：重点关注、详细数据、风险卡片与执行矩阵。
- `ParentTaskList.tsx` / `SubTaskList.tsx` / `ShopListPage.tsx` / `EntityTaskListPage.tsx`：批次、任务项和详情页。
- `TypeStatGroup`、`StatGroup`、`TaskFilterBar`、`TaskCard`、`ShopCard`、`ParentTaskDetailModal`、`SupervisionConfirmModal` 等现有组件。
- 复用当前 `theme.ts` 的 `MT` / `MT_THEME` / `MT_BTN`、共享页签和工作台响应式 CSS、品牌 PNG 与风险图案；不重建页面和视觉体系。

源码仅复制上述页面的依赖闭包。保留当前目录结构，方便继续编辑和定位。不复制无关的业务应用、部署脚本、内部配置、文档或 Git 历史。

## 仅在演示副本内的适配

- 独立 npm 依赖与锁文件、Vite 构建配置、Hash 路由及静态入口。
- 示例数据始终启用，替换原来只在 DEV + query/session 生效的开关。
- 服务层只调用本地数据；移除真实网络传输、SSO、埋点 SDK、环境跳转、远程微前端及网络字体。
- 侧栏提供外卖白领、连锁业务、下沉市场三种租户及 Test / Staging / Prod 三种环境展示；选项只控制本地样例与偏好，不连接对应业务环境。本地存储键加作品集前缀。
- 将工作台的 24 个样例批次关联到列表与详情，完整演示共 30 个批次（按租户限定品牌与拼好饭样例）；300 家外卖门店、30 家公海门店、4 个品牌，商家卡片按实体去重并由同一任务集生成详情。
- 远程助手 iframe 改为本地草稿流程；执行抽屉只模拟操作；督办确认明确标为模拟发送。
- 复用的编辑/反馈/移除界面采用内存示例数据，不保存到外部服务。工作台/矩阵数据是用于视觉展示的独立快照。
- 增加静态服务器、数据/资产/隔离边界验证脚本和接入文档。
- 按已确认调整复用线上风格的标签与批次名称、商家本地头像、SKU 分组与多选，移除空的 AI 执行结果提示；业务类型统计固定、筛选联动置灰、列表与详情默认范围一致。
- 工作台底部留白与左侧卡片间距统一为 20px。
- 商家名称与头像参考用户提供的线上展示；经营状态、地址、人员与执行结果均为演示数据。头像保存本地，来源记录随源码附带，不在浏览时远程加载。

新增的界面仅限远程服务位置的本地演示状态，不替换已有页面。新 UI 使用原有 Ant Design 组件与主题，无新 UI 库、无 Roo import/样式。演示运行链路不含 Roo；通过 iframe 文档边界隔离已有全局 reset，不污染作品集主站。

## 依赖与构建

依赖全部来自 npm 公共仓库，版本锁定在本工程 `package-lock.json`。保留当前 React 18、Ant Design 5、ECharts 6、Zustand 4、React Router 6 等页面运行依赖；构建工具由演示单独声明，不复用原业务工程的 node_modules 或构建器。

源工程与演示工程彼此独立。后续应在 `demo-src/task-agent/` 修改并执行 `npm run build`，而非手改静态 bundle。
